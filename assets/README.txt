HOW TO ADD YOUR PHOTOS
=======================

Each folder below matches a section of the site. Drop your photo in with
the EXACT filename shown (or rename your file to match) and it'll appear
on the site automatically — no code changes needed.

assets/hero/
  hero.png            → the big full-bleed photo behind "Light, held still."
                        (already filled with your uploaded shot)

assets/gallery/        → the 9-photo horizontal scroll section ("The Contact Sheet")
  01-scenery-shimla.jpg
  02-portrait-shimla.jpg
  03-moonshot-chandigarh.jpg
  04-concert-cgc-landran.jpg
  05-portrait-jibhi.jpg
  06-portrait-jalori-pass.jpg
  07-scenery-landran.jpg
  08-portrait-mini-thailand.jpg
  09-scenery-shimla-2.jpg

assets/selects/         → the 5-photo "Selects" grid
  a-moonshot-chandigarh.jpg   (large tile)
  b-portrait-jibhi.jpg
  c-scenery-shimla.jpg
  d-concert-cgc-landran.jpg
  e-scenery-shimla-2.jpg

assets/about/           → reserved for later (e.g. a small photo in the
                          About section, if you want to add one)

NOTES
-----
- File extension doesn't matter as much as the name before the dot —
  if you use a .png or .webp instead of .jpg, just update the matching
  <img src="..."> line in index.html to match.
- Filenames also double as labels/captions on the site, so swap photos
  into the SAME category (e.g. a portrait shot into a "portrait-*" slot)
  to keep captions accurate — or edit the caption text in index.html
  directly if the new photo is a different scene.
- Recommended sizes: gallery/selects images look best around 1200–2000px
  on the long edge. Hero image should be wide (16:9 to 21:9-ish landscape).
